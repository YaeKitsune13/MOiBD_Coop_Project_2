## Что нужно в api
1. API-запрос для расчёта стоимости с помощью предсказания нашей модели
2. Запросы для дашборда (список моделей, статистика по датасету, сравнение моделей, интерактивные графики)
3. Запрос для раздела "Справка" (Help)
4. Модель и препроцессоры загружаются один раз при старте приложения (например, через lifespan-события FastAPI), а не на каждый запрос

## Запросы

| запрос | информация |
|:-:|:-:|
| `api/ping` | для проверки работоспособности api |
| `api/predict` | запрос для расчёта предварительной стоимости, с валидацией входных данных и (опционально) доверительным интервалом прогноза |
| `api/dashboard/models` | список доступных моделей |
| `api/dashboard/models/comparison` | сравнение моделей и их метрики (на основе `model_comparison.csv`) |
| `api/dashboard/dataset/*` | статистика/графики по датасету (см. список ниже) |
| `api/dashboard/interactive/*` | запросы для интерактивных графиков |
| `api/info` | справка: описание приложения, полей ввода, модели и её ограничений, версия |

### Графики для `api/dashboard/dataset/*` (из ТЗ, п. 1.3)
- гистограммы ключевых числовых признаков (площадь, кол-во комнат, год постройки и т.д.)
- диаграммы рассеяния "признак — цена" для основных признаков
- boxplot по числовым признакам
- тепловая карта корреляций
- средние цены по категориям (район, тип дома и т.д.)

## `api/predict` — валидация и формат

**Обязательные/опциональные поля** — на основе словаря данных ниже, нужно явно зафиксировать:
- допустимые диапазоны (например, `size > 0`)
- допустимые значения для категориальных полей (`room_count`, `furnished`, `heating_type` и т.д.)
- обязательные vs опциональные поля

**Обработка ошибок ввода** — единый формат ответа с понятным сообщением пользователю (код ошибки + текст).

**Ответ** — точечный прогноз цены + опционально диапазон/доверительный интервал (например, `±MAE` лучшей модели из `model_meta.json`).

## Доп. инф.

### Словарь данных (описание столбцов)

| Название столбца | Описание | Примечания |
|---|---|---|
| **type** | Тип недвижимости | Konut = Жильё |
| **sub_type** | Подгруппа типа недвижимости | Daire = Квартира |
| **start_date** | Дата, когда объявление стало активным на рынке | |
| **end_date** | Дата, когда объявление перестало быть активным | |
| **listing_type** | Тип объявления | Satılık = Продажа; Kiralık = Аренда |
| **tom** | Время нахождения на рынке (Time on Market) | |
| **building_age** | Возраст здания | «arası» означает «между» (диапазон лет) |
| **total_floor_count** | Общее количество этажей в здании | |
| **room_count** | Количество комнат в квартире | Например, 2+1 означает: комнаты + гостиная |
| **size** | Площадь квартиры | в м² |
| **address** | Адрес недвижимости | город/район/микрорайон |
| **furnished** | Меблировка | Eşyalı = Меблировано; Eşyasız = Без мебели; Sadece Beyaz Eşya = только бытовая техника; Sadece Mutfak = только кухня |
| **currency** | Валюта цены на жильё | |
| **floor_no** | Номер этажа | Yüksek giriş = 1-й этаж; Giriş kat, Kot1, Zemin kat = цокольный/первый этаж; Çatı Katı = мансарда/пентхаус; Bahçe katı = квартира на уровне сада |
| **price** | Цена на жильё | |
| **heating_type** | Тип отопления | Kalorifer (Doğalgaz) = центральное/природный газ; Kalorifer (Kömür) = центральное/уголь; Kombi (Elektrikli) = электрический котёл; Klima = кондиционер; Kombi (Doğalgaz) = газовый котёл; Merkezi Sistem = центральное отопление; Merkezi Sistem (Isı Payı Ölçer) = центральное с счётчиком тепла; Yerden Isıtma = тёплый пол; Soba (Kömür) = печь/уголь; Soba (Doğalgaz) = печь/газ; Güneş Enerjisi = солнечная энергия; Jeotermal = геотермальная энергия; Fancoil = тип кондиционера (фанкойл); Kat Kaloriferi = поэтажное центральное отопление; Kalorifer (Akaryakıt) = центральное/жидкое топливо; Yok = отсутствует |
